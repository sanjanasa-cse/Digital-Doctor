# 🩺 Digital Doctor

Digital Doctor is an AI-powered healthcare assistance web application that helps users understand medicines and medical reports through AI-based image analysis. It also provides AI chat, voice support, history, and motivational guidance.

## ✨ Features

### 🔐 User Authentication
- User registration and login
- Email validation
- Password reset
- User profile management

### 📷 Camera & Image Upload
- Capture images using the device camera
- Upload images from the gallery
- Preview captured/uploaded images before scanning

### 💊 Tablet Scanner
Users can scan a tablet or medicine image to get:
- Medicine name
- Basic information
- Primary uses
- Precautions / things to avoid
- Motivational message

### 📄 Medical Report Scanner
Users can capture or upload a medical report and get:
- Report analysis
- Key findings
- Abnormalities
- Risk level
- Danger warnings
- Dietary recommendations
- Easy-to-understand explanation

### 🗣️ Kannada & English Voice Support
- Supports English and Kannada
- Translates the generated information
- Converts the result into speech
- Allows users to listen to the analysis

### 🤖 AI Health Chat
- AI-powered health assistant
- Users can ask health-related questions
- Provides conversational responses
- Supports voice interaction

### 📜 History
- Stores previous medicine scans
- Stores previous report scans
- Stores chat history
- Allows users to view previous results

### 🚨 Health Alerts
- Detects high-risk results
- Displays warning messages
- Provides audio alerts
- Uses device vibration when supported

### 💭 Motivational Support
- Provides motivational messages along with health information
- Encourages users with positive thoughts
